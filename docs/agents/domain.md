# Domain docs

Single context. Before exploring, read:

- `GLOSSARY.md` at the repo root, if it exists.
- `docs/adr/`, if it exists, for decisions touching the area you work in.
- `HANDOFF.md` "Key decisions" for decisions made before ADRs existed.

If a file is missing, proceed silently. The `domain-modeling` skill creates `GLOSSARY.md` and
ADRs lazily when a term or decision is actually resolved.

Use the glossary's terms in names, tests and tickets. If output contradicts an ADR or a HANDOFF
decision, say so explicitly instead of overriding it.

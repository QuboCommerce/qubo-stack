The media library now groups files by what uses them: Products, Pages, Brand, Blog, Documents, and Scratch for everything else. Products show as cards with their reference and photos, and a search such as `JBM-` finds every product whose reference starts with it. Files can be tagged, shared or deleted in bulk, and uploading the same file twice reuses the first copy. The image picker opens on the right group for what you are editing. Markdown and JSON files can be uploaded. In the product editor each variant can pick its own photos from the product gallery, and the catalogue API returns them.

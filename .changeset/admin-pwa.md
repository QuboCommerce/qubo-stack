The admin installs as an app. Add to Home Screen opens it full screen with PNG and Apple icons, a status bar that blends into the top bar, and shortcuts to the site's main sections. On phones a bottom tab bar replaces the hamburger: Home, the site's three main sections and More. The layout respects the notch and home indicator, form fields no longer zoom on focus, and the tab bar steps aside for the keyboard. A small service worker caches build assets and shows an offline page instead of the browser error. "Install app" in the user menu prompts on Android and desktop and explains the steps on iOS; installed, the same menu offers Reload.
